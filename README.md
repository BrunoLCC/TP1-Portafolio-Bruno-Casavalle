# TP1 - Portfolio con React

**Alumno:** Bruno Casavalle

## Descripción

Este es mi portfolio personal, hecho con React y Vite para el TP1. Tiene una sección de presentación, sobre mí, habilidades, proyectos y contacto.

## Tecnologías

- React
- Vite
- JavaScript
- CSS

## Cómo instalarlo

Hay que tener Node.js instalado.

```bash
git clone https://github.com/BrunoLCC/TP1-Portafolio-Bruno-Casavalle.git
cd TP1-Portafolio-Bruno-Casavalle
npm install
```

## Cómo ejecutarlo

```bash
npm run dev
```

Después abrir http://localhost:5173 en el navegador.
